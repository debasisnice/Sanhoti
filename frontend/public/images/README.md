# Logo Image

Please place your logo image file here as `logo.png`.

The logo image should be:
- Format: PNG (recommended) or SVG
- Name: `logo.png`
- Description: Red background with white circle containing plant sprout and two children

The logo will be automatically displayed in:
- Navigation bar (navbar)
- Homepage hero section
- Footer

If the image is not found, the text "সানহোটি" will be displayed as a fallback.
