# PWA Mobile App Setup

Your Sanhoti website is now a **Progressive Web App (PWA)** that can be installed on mobile devices!

## What is PWA?

A Progressive Web App (PWA) is a web application that can be installed on mobile devices and works like a native app:
- ✅ **Installable** - Users can add it to their home screen
- ✅ **Offline Support** - Works offline with cached content
- ✅ **App-like Experience** - Full-screen, no browser UI
- ✅ **Fast Loading** - Optimized caching strategies
- ✅ **Push Notifications** - Can receive notifications (future enhancement)
- ✅ **No App Store Required** - Install directly from browser

## How Users Can Install the App

### On Android (Chrome):
1. Visit https://sanhoti.org on Chrome browser
2. A popup will appear: "Add to Home screen" or "Install app"
3. Tap "Install" or the menu (⋮) → "Add to Home screen"
4. The app will be added to the home screen with the Sanhoti logo

### On iOS (Safari):
1. Visit https://sanhoti.org on Safari browser
2. Tap the Share button (square with arrow) at the bottom
3. Scroll down and tap "Add to Home Screen"
4. Customize the name (default: "Sanhoti")
5. Tap "Add"
6. The app will appear on the home screen

### On Desktop (Chrome/Edge):
1. Visit https://sanhoti.org
2. Click the install icon in the address bar (or menu → "Install Sanhoti")
3. Click "Install"
4. The app opens in its own window

## Features Included

### Service Worker (Automatic)
- Caches static assets (HTML, CSS, JS, images)
- Offline functionality for visited pages
- Automatic updates when new version is deployed

### App Manifest
- App name: "Sanhoti - Bengali Association of Orange County"
- Short name: "Sanhoti"
- Theme color: Gold (#B8860B)
- Display mode: Standalone (no browser UI)
- App icons: Uses logo.png

### Quick Shortcuts
Users can long-press the app icon to access:
- Events
- Notices
- Galleries

### Caching Strategy
- **Static Assets**: Cached immediately (CSS, JS, images)
- **Google Fonts**: Cached for 1 year
- **API Calls**: Network-first with 5-minute cache
- **HTML Pages**: Cached on first visit

## Deployment

After deploying to AWS, the PWA will automatically be available:

```bash
cd /var/www/sanhoti
git pull origin main
cd frontend
npm ci
npm run build
cd ..
sudo systemctl reload nginx
```

The service worker will be automatically generated during the build process.

## Testing Locally

1. Start the development server:
   ```bash
   cd frontend
   npm run dev
   ```

2. Open http://localhost:3000 in Chrome

3. Open DevTools → Application tab → Service Workers
   - You should see the service worker registered

4. In DevTools → Application tab → Manifest
   - Check that all manifest properties are correct

5. Test installation:
   - Look for install prompt in address bar
   - Or use DevTools → Lighthouse → Run audit (PWA section)

## Troubleshooting

### Service Worker Not Updating
- Users may need to close all tabs and reopen
- Or: Settings → Privacy → Clear browsing data → Cached images and files

### App Not Installing
- Ensure the site is served over HTTPS (required for PWA)
- Check browser console for errors
- Verify manifest.json is accessible at /manifest.json

### Icons Not Showing
- Ensure logo.png exists at /public/images/logo.png
- Clear browser cache
- Check manifest.json icon paths
