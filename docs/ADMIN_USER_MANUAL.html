1. Getting Started

1.1 Accessing the Admin Panel

To access the Sanhoti admin panel, follow these steps:

  1. Open your web browser and navigate to https://www.sanhoti.org
  2. Click on the "Login" button in the navigation bar
  3. Enter your admin email address and password
  4. Click "Sign In"
  5. Once logged in, click on your profile icon and select "Admin Dashboard"

3. Events Management

The Events section allows you to create, edit, and manage all community events including festivals, cultural programs, and gatherings.

3.1 Viewing Events

The events list displays all events organized by year. You can filter events by year using the filter buttons at the top.

📷 Screenshot: Events List View
(Insert screenshot of events management page here)

Event Status Indicators:

  • Green background - Active event (visible to public)
  • Star icon (⭐) - Priority event (featured on homepage)
  • Eye icon - Toggle visibility

3.2 Creating a New Event

  1. Click the "Add Event" button in the top-right corner
  2. Fill in the event details:
    • Event Name (required) - e.g., "Durga Puja 2026"
    • Start Date & Time (required) - When the event begins
    • End Date & Time (required) - When the event ends
    • Year (required) - The event year for filtering
    • Description (required) - Detailed event description
    • Location (optional) - Venue address
    • RSVP Link (optional) - External RSVP form URL
  3. Check "Mark as Priority Event" if this should be featured on the homepage
  4. Upload an Event Image/Flyer (optional but recommended)
  5. Click "Create Event"
📷 Screenshot: Create Event Form
(Insert screenshot of create event popup form here)
Only ONE event can be marked as Priority at a time. When you mark a new event as priority, the previous priority event will automatically be unmarked.

3.3 Editing an Event

  1. Find the event in the list
  2. Click the Edit icon (✏️) in the Actions column
  3. Modify the desired fields
  4. Click "Update Event"
When editing an event, the start and end times will be pre-populated if they were previously set.

3.4 Managing Sub-Events

Large events like Durga Puja can have multiple sub-events (e.g., Puja days, cultural programs).

  1. Find the parent event in the list
  2. Click "Add Sub Event" below the event
  3. Fill in sub-event details:
    • Sub-event name
    • Start/End date and time
    • Description and location
    • Enable RSVP if needed
    • Check "Show in Home Page" to display on homepage
  4. Click "Create Sub-Event"

4. Notices Management

The Notices section allows you to create and publish announcements that appear on the Notice Board page.

4.1 Creating a Notice

  1. Click "Add Notice" button
  2. Enter the notice details:
    • Title - Brief, descriptive title
    • Content - Full notice text
    • Priority - Normal, Important, or Urgent
  3. Upload any attachments or images (optional)
  4. Check "Publish" to make it visible immediately
  5. Click "Create Notice"

4.2 Notice Priority Levels

Priority Display Use Case
Normal Standard styling General announcements
Important Yellow highlight Event reminders, deadlines
Urgent Red highlight Emergency announcements, cancellations

4.3 Managing Notice Images

You can attach multiple images to a notice:

  • Supported formats: JPEG, PNG, GIF, WebP
  • Maximum file size: 10MB per image
  • Images appear in a gallery format on the notice
Use high-quality images for better presentation. Compress large images before uploading to improve page load times.

5. Photo Galleries

The Galleries section manages photo and video collections for each event. Every event automatically gets a gallery folder created.

5.1 Viewing Galleries

Galleries are listed by event, sorted with the most recent events first. Each gallery shows:

  • Event name and year
  • Number of photos/videos
  • Public/Private status
  • Thumbnail preview
📷 Screenshot: Galleries List
(Insert screenshot of galleries management page here)

5.2 Uploading Photos & Videos

  1. Find the event gallery in the list
  2. Click "View Gallery" or the gallery card
  3. Click "Upload Files" button
  4. Select one or multiple files:
    • Photos: JPEG, PNG, GIF, WebP (max 10MB each)
    • Videos: MP4, MOV, AVI, WebM (max 100MB each)
  5. Wait for upload to complete
📷 Screenshot: Gallery Upload
(Insert screenshot of gallery with upload interface here)

5.3 Publishing a Gallery

By default, galleries are private. To make them publicly visible:

  1. Find the gallery in the list
  2. Click the "Publish" button
  3. Confirm the action
Publishing a gallery makes all its photos and videos visible on the public Galleries page. Ensure all content is appropriate before publishing.

5.4 Deleting Photos

  1. Open the gallery
  2. Hover over the photo/video you want to delete
  3. Click the delete icon (🗑️)
  4. Confirm the deletion
Deleted photos cannot be recovered. Make sure you have backups of important images.

14. Troubleshooting

14.1 Common Issues

Issue: Unable to upload images

Solution:

  • Check file size (images: max 10MB, videos: max 100MB)
  • Ensure file format is supported (JPEG, PNG, GIF, WebP for images)
  • Try refreshing the page and uploading again
  • Clear browser cache if the problem persists

Issue: Changes not appearing on public site

Solution:

  • Ensure the item is marked as "Active" or "Published"
  • Clear your browser cache (Ctrl+Shift+R or Cmd+Shift+R)
  • Check if the feature is enabled in Settings (navbar visibility)

Issue: Session expired / Logged out unexpectedly

Solution:

  • Admin sessions expire after 30 minutes of inactivity
  • Simply log in again to continue
  • Save your work frequently when editing long content

Issue: Priority event not showing on homepage

Solution:

  • Ensure the event has an image uploaded
  • Verify the event is marked as "Active"
  • Check that "is_priority" is checked in the event settings

14.2 Getting Help

If you encounter issues not covered in this manual:

  • Contact the technical administrator
  • Check the Audit Logs for recent changes that might have caused the issue
  • Document the exact steps to reproduce the problem

14.3 Best Practices

  • Regular backups: Ensure data is backed up regularly
  • Image optimization: Compress images before uploading
  • Consistent naming: Use clear, descriptive names for events and documents
  • Review before publishing: Double-check content before making it public
  • Keep passwords secure: Use strong passwords and don't share admin credentials
