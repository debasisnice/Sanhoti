## Part 2 — Prioritized SEO checklist

### Do now (one-time setup)
- [ ] **Google Search Console** — verify the domain, submit `sitemap.xml`.
- [ ] **Request indexing** (URL Inspection) for: `/durga-puja-2026`, both `/sub-events/<concert-id>` pages, `/become-our-sponsor`, and the homepage.
- [ ] **Bing Webmaster Tools** — add the site + sitemap (also feeds Copilot/ChatGPT search).
- [ ] Confirm both concerts exist as **sub-events** with "Generate SEO page" ON: correct **performer name**, **type = MusicEvent**, **venue** (Orange Coast College, Costa Mesa, CA + "Orange County" area), **date/time**, **ticket link + price**.
- [ ] Double-check **artist name spelling** everywhere matches how people search.
- [ ] **Business Profile:** primary category = Cultural association; add secondaries (Non-profit organization, Association or organization, Event planner); complete description, service area (Orange County + SoCal), hours, website, and the WhatsApp chat link.
- [ ] Put the **"Review us on Google"** link in the footer (done) and the **QR on event flyers/print**.

### This week
- [ ] Post both concerts to **Facebook, Instagram, WhatsApp** (captions above).
- [ ] Add a **photo** to each Google Business Profile event post.
- [ ] List Sanhoti on: **Bing Places, Apple Business Connect, Yelp, GuideStar/Candid**, and community/event sites (**Sulekha, IndiaCurrents, local OC event calendars, Eventbrite** if selling there) — keep name/phone/area identical everywhere (NAP consistency).
- [ ] Ask **3–5 partners/sponsors** to link to the event/concert pages.

### Monthly (ongoing — this is what keeps you at the top)
- [ ] Publish **2–4 Google Posts** (events, updates, photos).
- [ ] Collect a **few new reviews**; reply to every one.
- [ ] Add **fresh photos** to the profile.
- [ ] Check **Search Console**: which queries/pages are ranking → double down; fix any coverage errors.
- [ ] Refresh site content (schedule, artists, details) as they firm up.

### Each event cycle (yearly)
- [ ] Update the Durga Puja page + sub-events for the new year.
- [ ] New concert pages + Google/social posts.
- [ ] Replace the sponsorship prospectus PDF.
- [ ] Re-submit sitemap / request indexing for the new pages.

### Never (these cause suspensions or penalties)
- Don't stuff the Business Profile **name** with keywords/location beyond your real name.
- Don't **buy links or fake reviews**.
- Don't make **rapid repeated profile edits**.

---

### Realistic expectations
- **Most winnable:** "Bengali Association in Orange County", "Akriti Kakar / Subhadeep Live Concert in Orange County", "Durga Puja near me" (Business Profile + your dedicated pages).
- **Hardest:** bare "Durga Puja 2026" (global competition) — target geo-qualified versions instead ("Durga Puja 2026 Orange County / Costa Mesa / near Irvine").
- New domain + profile → give it a few weeks; Search Console indexing + a handful of backlinks accelerate it.
